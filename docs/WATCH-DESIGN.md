# WATCH 시리즈 공통 디자인 시스템 v1

BOK워치·FX워치·DEBT워치·APT워치를 한 브랜드로 읽히게 하는 규칙. 서비스는 각자 독립 운영하고, 이 규칙은 **토큰(CSS 변수) → 카드 → 차트 → 헤더** 순으로 복사해 적용한다. 프레임워크는 바꾸지 않는다.

## 분석 결과 (2026-11-12 실측)
- BOK워치와 DEBT워치는 색 토큰이 16진수까지 같다(`--bg #f6f6f4`, `--ink #0b0b0b`, `--hike #eb6834`, `--cut #2a78d6` 등). 시리즈의 기준이다.
- FX워치는 같은 방향색(`--up/--down`)을 쓰지만 다크 배경이 `#1e1e1e`, 카드 반경 12px에 그림자가 있어 어긋난다(Tailwind 빌드).
- 처음 APT워치는 녹색 팔레트·Inter·4.5rem 헤드라인으로 가장 달랐다.
- 서비스 이름은 `BOK워치`처럼 한글 "워치", 로고 옆에 영문 `BOK Watch` 부제.

## 토큰 — `site/watch-tokens.css`
| 용도 | 변수 | 라이트 | 다크 |
|---|---|---|---|
| 배경/카드/보조면 | `--bg` `--surface` `--surface-2` | #f6f6f4 / #fcfcfb / #efeeea | #121211 / #1a1a19 / #232321 |
| 선 | `--line` | #dcdbd6 | #34342f |
| 글자 | `--ink` `--ink-2` `--ink-3` | #0b0b0b / #52514e / #7a7974 | #f0efec / #c3c2b7 / #95948c |
| 상승·하락 | `--up` `--down` | #eb6834 / #2a78d6 | #d95926 / #3987e5 |
| 중립 | `--hold` | #8a8984 | #7d7c76 |
| 경고·오류 | `--warn-*` `--bad-*` | 노랑 / 빨강 계열 | 어두운 대응색 |
| 잠정·축적 중 | `--wip-bg` `--wip-ink` | 회색(`--surface-2`) | 동일 |

**색의 의미 규칙**: `--up`(주황)은 "값이 올랐다", `--down`(파랑)은 "값이 내렸다"는 방향만 뜻한다. 환율·금리·집값 상승을 좋다/나쁘다로 칠하지 않는다. 좋고 나쁨을 말해야 하면 문장으로 쓴다. 빨강·초록은 상승·하락에 쓰지 않는다. 경고·오류는 `--warn-*`/`--bad-*`만 쓴다. 서비스별 강조색은 로고 외에는 쓰지 않는다.

## 타이포그래피
- 글꼴: 시스템·Pretendard·Noto Sans KR·맑은 고딕, 숫자는 `font-variant-numeric: tabular-nums`.
- 서비스 제목 22px/700 · 핵심 숫자 28px/700(모바일 24px) · 지표명 12px/600 `--ink-3` · 섹션 제목 18px · 본문 15px · 보조·기준일·출처 11–12px.
- 숫자 계층: 큰 숫자 → 단위·변화폭(작은 글씨) → 기준일. 설명이 숫자보다 눈에 띄면 안 된다.
- 데이터가 없는 숫자 자리는 20px 회색 "데이터 축적 중". 표는 `–`.

## 핵심 지표 카드 (납작한 줄 스트립)
순서: **지표명 → 핵심 숫자 → 한 줄 설명 → 참고·변화 줄(점선 상자, 선택) → 기준일**. 박스·그림자 없이 위아래 1px 선과 카드 사이 세로선만 쓴다. 같은 정보(관측 단지 수·기준일 등)는 카드마다 반복하지 않고 헤더 메타 줄에 한 번만 둔다. 대표값이 아닌 참고치는 점선 상자의 작은 글씨로만 보인다.

## 차트
- 선 2px `--ink`(방향 중립), 격자 `--line` 1px, 기준선(100 또는 0)은 `--ink-3` 점선, 잠정 구간은 점선, 자료가 없는 기간은 **선을 잇지 않는다**(보간 금지, 단일 점은 점으로).
- 집계 주기가 다른 지표는 한 축에 겹치지 않고 따로 그린다.
- 기간은 `전체/5년/1년/3개월` 세그먼트 버튼. 호버·터치·←→ 키로 십자선과 값 읽기줄이 움직인다.
- 자료가 없으면 빈 캔버스 대신 이유를 쓴 점선 상자.

## 헤더·내비게이션
위 줄 `.svc` 알약 내비(4개 서비스, 현재 서비스만 검정 채움, 모바일은 가로 스크롤) → `.top`: 로고 40px + 서비스명 + 영문 부제, 갱신·기준 메타 줄, 테마 버튼. "WATCH SERIES" 문구는 따로 크게 쓰지 않는다.

## 화면 구성 (5단계)
① 상태와 핵심 지표 → ② 시계열 → ③ 원인·구성 → ④ 지역·기간 비교 → ⑤ 출처·기준일·표본·산출법(접기). 서비스 기능을 억지로 끼워 맞추지 않는다. 보조 설명은 `<details class="more">`로 접고, 모바일에서는 기본으로 닫는다.

## 컴포넌트 대응 (CSS 클래스 → 장기 이름)
`.svc`=WatchNavigation · `.top`=WatchHeader · `.strip .tile`=WatchMetricCard · `.panel .chart`=WatchChartContainer · `.seg`=WatchPeriodSelector · `.badge`=WatchStatusBadge · `.meta`·`.asof`=WatchDataSource · `details.more`=WatchMethodology · `footer`=WatchFooter.

## 반응형 기준
320 / 390 / 768 / 1280px에서 가로 스크롤이 없어야 하고, 760px 이하에서는 지표 카드 한 줄 쌓기, 차트 높이 230px, 표 글자 13px.

## 다른 서비스에 남은 불일치 (수정 가이드)
| 대상 | 현재 | 맞출 방법 |
|---|---|---|
| FX워치 | 다크 `#1e1e1e` 계열, 카드 반경 12px + 그림자 | 토큰 파일 값으로 교체, 반경 10px, 그림자 제거 |
| FX워치 | 기간 버튼 모양이 BOK·DEBT와 다름 | `.seg` 규칙 적용 |
| BOK·FX·DEBT | 서비스 내비에 APT워치 없음 | APT워치 공개 주소가 정해지면 `.svc`에 링크 한 줄 추가 (현재 APT워치는 로컬 전용이라 미반영) |
| BOK·DEBT | 카드가 박스형·줄 스트립 혼재 | BOK의 줄 스트립을 기준으로 통일 |
